# Consent tiers — outward acts

Binds whenever an act's effect leaves this session — reaching other people, other systems, or a shared record — and to the authority a message hands an agent. What is judged is the act and the authority it grants.

- **Contract**: an explicit approval choi constituted before execution, in whatever form the work was set up through, naming the kinds of act, their targets and the authority they carry. It covers runtime acts whose text was unknown then. It reaches only its named scope and unit; silence never counts; it crosses a session only where it is recorded where the next session reads.
- **Setup**: before work runs while choi is away, list the outward-act kinds it will reach, by tier below, and ask once — through `/bound` where the boundary is unclear. What choi grants is the contract, recorded where the executing session reads it.
- **Do, then report**: a thread continuation answering an agent inside an assignment already approved; a request whose content choi directed this session and whose granted authority is non-destructive.
- **Ask once in the session, unless the contract allows**: merging a PR choi opened, personal or work org — a work-org PR once review approval or branch protection permits it; staging changes; work-org Linear writes; a post granting an agent authority beyond the tier above; and, in any tier, an act whose target differs from the one the context shows, whose state has drifted from what the contract or an earlier answer assumed, or that contradicts a direction choi stated or a decision already settled. The question offers to let acts of that kind proceed on their own from then on; a yes is a contract. With the contract's allowance, proceed and report — post-merge tests are the check.
- **Destructive acts**: the harness's auto-mode classifier restricts them, beneath these tiers. A denied act is parked and reported like any other, and its outcome waits on choi.
- **Running autonomously**: an act that needs asking is parked alone as a draft; independent work continues, and every parked act is gathered in the final report.
