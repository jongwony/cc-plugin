# Rendering catalog

Generated by `scripts/catalog.py` — do not edit by hand. Every case below
is rendered at 80 columns by the renderer in this repository, so the
drawings are what you actually get rather than what the prose claims.

Regenerate with `uv run scripts/catalog.py --write`; `--check` fails when a
renderer change has moved any output.

## Fan-out and fan-in

The shape the layered renderer is built for: one source spreading to N parallel stages that gather back into one.

**Input**

```
start -> A, B, C
A, B, C -> verify -> report
```

**Output**

```
      ┌───────┐
      │ start │
      └───────┘
  ┌───────┼───────┐
  │       │       │
┌───┐   ┌───┐   ┌───┐
│ A │   │ B │   │ C │
└───┘   └───┘   └───┘
  └───────┼───────┘
          │
     ┌────────┐
     │ verify │
     └────────┘
          │
          │
     ┌────────┐
     │ report │
     └────────┘
```

## Widest layer inside the budget

Four siblings with short labels. Sum of labels + 4n + 3(n-1) lands under 80, so nothing is reported.

**Input**

```
root -> aa, bb, cc, dd
```

**Output**

```
            ┌──────┐
            │ root │
            └──────┘
   ┌────────┬───┴────┬────────┐
   │        │        │        │
┌────┐   ┌────┐   ┌────┐   ┌────┐
│ aa │   │ bb │   │ cc │   │ dd │
└────┘   └────┘   └────┘   └────┘
```

<a id="width-overflow"></a>

## Widest layer past the budget

The same shape with long labels. The renderer appends an over-budget notice instead of emitting a drawing the terminal will hard-wrap.

**Input**

```
root -> extraction-stage, validation-stage, aggregation-stage, delivery-stage
```

**Output**

```
                                        ┌──────┐
                                        │ root │
                                        └──────┘
          ┌──────────────────────┬──────────┴───────────┬──────────────────────┐
          │                      │                      │                      │
┌──────────────────┐   ┌──────────────────┐   ┌───────────────────┐   ┌────────────────┐
│ extraction-stage │   │ validation-stage │   │ aggregation-stage │   │ delivery-stage │
└──────────────────┘   └──────────────────┘   └───────────────────┘   └────────────────┘

over budget: 88 columns (budget 80), widest layer has 4 boxes.
  Terminals hard-wrap past their width, which breaks the drawing.
  Shorten labels, split the graph, or move siblings to another layer.
```

<a id="shared-bus"></a>

## Two parents, one connector bus

Both parents feed the same layer, and the connectors are drawn as one shared bus — so which child came from which parent is NOT readable here. Split the graph or push a child to its own layer when that matters.

**Input**

```
left -> x, y
right -> z
```

**Output**

```
┌──────┐   ┌───────┐
│ left │   │ right │
└──────┘   └───────┘
  ┌─┴─────┬────┴──┐
  │       │       │
┌───┐   ┌───┐   ┌───┐
│ x │   │ y │   │ z │
└───┘   └───┘   └───┘
```

## Edge that skips a layer

`start -> end` jumps past the middle. The renderer lists it beneath the drawing rather than routing a line that would read as passing through.

**Input**

```
start -> mid -> end
start -> end
```

**Output**

```
┌───────┐
│ start │
└───────┘
    │
    │
 ┌─────┐
 │ mid │
 └─────┘
    │
    │
 ┌─────┐
 │ end │
 └─────┘

cross-layer edges (not drawn above):
  start ⇢ end
```

## Back edge

Layering is cycle-safe (back edges contribute 0), so this lays out — but it reads as a tree, not as a loop. Reach for graph-easy when the cycle is the point.

**Input**

```
a -> b -> c -> a
```

**Output**

```
┌───┐
│ b │
└───┘
  │
  │
┌───┐
│ c │
└───┘
  │
  │
┌───┐
│ a │
└───┘

cross-layer edges (not drawn above):
  a ⇢ b
```

## One focal node

Heavy strokes carry emphasis because assistant output reaches the terminal as plain characters and no colour survives. Marking more than one spends the only contrast channel there is.

**Input** — `--focus test`

```
plan -> build, test, ship
```

**Output**

```
           ┌──────┐
           │ plan │
           └──────┘
    ┌──────────┴┬──────────┐
    │           │          │
┌───────┐   ┏━━━━━━┓   ┌──────┐
│ build │   ┃ test ┃   │ ship │
└───────┘   ┗━━━━━━┛   └──────┘
```

<a id="cjk"></a>

## CJK labels misalign — a known limit

Box width is len(label) + 4, and CJK characters occupy two terminal cells, so these boxes come out narrower than their contents and the connectors drift. This case exists to keep that visible; use Latin labels when alignment matters.

**Input**

```
시작 -> 분석, 검증
분석, 검증 -> 보고
```

**Output**

```
    ┌────┐
    │ 시작 │
    └────┘
   ┌───┴────┐
   │        │
┌────┐   ┌────┐
│ 분석 │   │ 검증 │
└────┘   └────┘
   └───┬────┘
       │
    ┌────┐
    │ 보고 │
    └────┘
```

<a id="dot-paste"></a>

## Pasted DOT body

Quotes, trailing semicolons, `[label=...]` blocks and the digraph wrapper are stripped, so a .dot body pastes in directly — as long as the wrapper braces sit on their own lines.

**Input**

```
digraph G {
  "load" -> "clean" [label="step 1"];
  "clean" -> "score";
}
```

**Output**

```
┌──────┐
│ load │
└──────┘
    │
    │
┌───────┐
│ clean │
└───────┘
    │
    │
┌───────┐
│ score │
└───────┘
```
